Flow Autopilot — ตั้งค่า

Automation นี้ทำงาน 100% ในเบราว์เซอร์ของคุณ โดยใช้ session ที่ล็อกอินอยู่แล้ว ไม่มี server กลาง ไม่มีการแชร์ credential ระหว่างผู้ใช้ — แต่การจำลองคลิก/พิมพ์บน ChatGPT และ Google Flow อาจขัดกับ ToS ของแต่ละแพลตฟอร์ม ความเสี่ยงเป็นของผู้ใช้แต่ละคนเอง

เปิด custom GPT ที่คุณต้องการใช้วิเคราะห์รูปสินค้าใน ChatGPT แล้ว copy URL จาก address bar มาวางที่นี่ (เช่น GPT "รีวิวสินค้า minimal" จาก Crewbank.com ตามคลิปต้นแบบ หรือ custom GPT ของคุณเอง)

ข้อความนี้จะถูกพิมพ์ในแชทพร้อมรูปสินค้าที่คุณเลือกใน popup

เนื่องจาก DOM ของ ChatGPT/Google Flow เปลี่ยนบ่อยและการแยกข้อความอัตโนมัติอาจไม่สมบูรณ์แบบ การเปิดตัวเลือกนี้ (ค่าเริ่มต้น) จะหยุดให้คุณตรวจ/แก้ prompt ก่อนไปขั้นถัดไป — ปิดได้ถ้าต้องการรันอัตโนมัติเต็มรูปแบบ
